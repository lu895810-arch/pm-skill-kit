# cyx-multi-project-analysis 反馈账本

> 本账本记录每次使用本技能时用户提的修改意见，按 `cyx-skill-evolution` 通用条款沉淀。
> 同一类别反馈出现 2 次以上，从「建议」升级为「强约束」并标注「高频」。

## 种子经验（首例：9 个 AI 短视频生产 Skills 仓库盘点，2026-09-30）

- #1 · 2026-09-30 ·「这个顺序要按照制作短剧的先后顺序排列，现在没有一点逻辑」→ 类别：排序逻辑 → 落点：二（流水线排序法）·处置：新增。所有章节按业务链路（创意→剧本→分镜→一致性→剪辑）统一排序，同环节内按 Star。
- #2 · 2026-09-30 ·「这一章节不要了，重新梳理结构」→ 类别：结构增删 → 落点：三/五 → 处置：修订。删独立许可证章后，目录、后续序号、无用 CSS 要一并清。
- #3 · 2026-09-30 ·「将目录放在左侧」「现在视觉割裂，请重新布局」→ 类别：布局 → 落点：三（布局）/ 五 → 处置：新增。改全高左栏通栏 + 占满正文的 grid，去居中浮岛。
- #4 · 2026-09-30 ·「这个不要了（截图：黄色许可证提示块）」「全文的这种都不要了」→ 类别：语言版式 → 落点：四.4 ·处置：新增。删逐卡黄色 note，信息收口到「数据口径」块。
- #5 · 2026-09-30 ·「这一列，括号的内容都不要了」→ 类别：语言版式 → 落点：四.3 ·处置：新增。许可证列写「未声明」不写「未声明（标 MIT）」。
