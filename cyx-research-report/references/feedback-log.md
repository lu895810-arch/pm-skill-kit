# 反馈日志 · feedback-log

> 本文件是**本技能包（三个 skill）共用的「进化账本」**：`cyx-research-report`、
> `cyx-md-style`、`cyx-html-style` 的每轮用户反馈里**可复用的部分**都记在这里，
> 对应的规则改动写进**各自 skill** 的进化条款（主文件「十六」/ md 文件「六」/ html 文件「七」）。
>
> **追加规则**：只记**通用规则**，不记个案；一行一次；**「归属 skill」列必填**（一条反馈跨两个
> skill 时填两个）；同一类别再次出现时在「处置」列标注「高频」，并在对应 skill 里把该条从
> 「建议」升级为「强约束」。个案（只对这一份报告成立的结论、数字）不入本表。
