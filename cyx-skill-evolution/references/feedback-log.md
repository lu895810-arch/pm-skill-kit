# 反馈账本 · feedback-log（cyx 技能通用）

> **本账本服务于所有 `cyx-*` 技能**：每个技能被使用后，用户在过程中提的修改意见、补充、纠偏，
> 凡判定为**通用规则**的，都按 `cyx-skill-evolution` 的格式在这里追加一行；规则本体写进对应 skill。
>
> **为什么集中在母版目录**：多数技能目录下没有 `references/`，分散建账会让规则散落、无法对照。
> 已经自带账本的技能包（`cyx-research-report` 三 skill、`cyx-ears-need`、`cyx-summary-need`）**优先写各自那本**，
> 其余技能一律写本文件——**一个技能只有一本账，不要两头都写**。
>
> **追加规则**：一行一次；只记**通用规则**，个案（只对这一份产物成立的结论、数字）不入表；
> 「归属技能」列必填；同类再次出现时在「处置」列标「高频」，并把该条在对应 skill 里从「建议」升为「强约束」。

## 格式

```
| # | 日期 | 用户原话（节选） | 类别 | 归属技能 | 落点（文件 · 章节） | 处置 |
```

类别代号沿用通用分档：A 事实与依据 / B 遣词与命名 / C 视角与元信息 / D 结构与层次 / E 术语与可读性 / F 排版与视觉 / G 流程与命令 / 组织 skill 自身机制。
