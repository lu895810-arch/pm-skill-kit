pm-agent 技能包（含第三方改造适配技能）

pm-agent Skills Pack (with third-party adapted skills)

面向 WorkBuddy 的自定义技能集合 · 中文 / English 双语
A custom skill collection for WorkBuddy · bilingual Chinese / English

这是一套面向 WorkBuddy（以及兼容 Anthropic Agent Skills 规范的工具）的自定义技能集合，分两部分：一是由作者自己沉淀的原创技能；二是第三方作者创作、由作者适配到 WorkBuddy 环境的技能。每个技能是一个独立目录，里面是 SKILL.md 加脚本、模板或参考文件。

A custom skill collection for WorkBuddy (and tools compatible with the Anthropic Agent Skills spec). It has two parts: skills authored and maintained by the repo owner, and skills created by third-party authors and adapted into the WorkBuddy environment by the owner. Each skill is a standalone folder containing a SKILL.md plus scripts, templates, or references.

这套包里有什么What's inside

1. 作者原创技能——cyx- 系列（作者把实际工作里反复打磨的方法论沉淀成技能）+ 少量自建工具技能。这些由作者自己写、自己维护。

1. Original skills by the author — the cyx- series (the author's battle-tested methodologies turned into skills) plus a few self-built utility skills, all written and maintained by the author.

2. 改造适配技能——由第三方作者创作，由作者（Lulu）自行适配到 WorkBuddy 环境（部分做了运行时接线、依赖安装、shim 等改造，详见各技能 SKILL.md 内的适配说明）。

2. Adapted third-party skills — created by third-party authors and adapted into the WorkBuddy environment by the author (Lulu). Some needed runtime wiring, dependency install, or shims; see each skill's SKILL.md for adaptation notes.

每个技能条目讲清三件事：做什么 / 解决什么问题 / 适合场景，并标注作者归属〔原创〕或〔改造适配 · 原作者〕。

Each skill entry states three things: what it does / what problem it solves / when to use it, and is tagged [Original] or [Adapted · original author].

同系技能多、名字相近分不清走哪个时，查仓库根目录的 SKILL-ROUTES.md——按「产出物 → 落点」整理的路由表。

When similar skills blur together, check SKILL-ROUTES.md at the repo root — a routing table organized by "deliverable → destination".

怎么装How to install

把需要的技能目录整个复制到 WorkBuddy 的技能目录，重启或刷新即可识别。只用其中一部分也行，但凡是标注了「上游 / 下游」的，缺了上游产物下游就跑不起来，装的时候一并装上。

Copy the skill folders you need into WorkBuddy's skills directory, then restart or refresh to load them. You can use a subset, but if a skill is marked with an upstream/downstream dependency, install the upstream too or it won't run.

~/.workbuddy/skills/

改造适配类技能如果带运行依赖（如 archify 需要 npm install、drawio-* 需要 drawio-ai 引擎），请按对应 SKILL.md 里的适配说明先把依赖装好。

Adapted skills with runtime dependencies (e.g. archify needs npm install; drawio-* needs the drawio-ai engine) require you to install those deps per the skill's adaptation notes first.
