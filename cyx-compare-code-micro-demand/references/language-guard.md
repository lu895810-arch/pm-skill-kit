# 语言禁词库与两轮回扫（cyx-compare-code-micro-demand）

对比需求文档最容易带的三种毛病：**AI 味标签 / 套话、行业缩语、口语词**。这三类在不同轮次被用户分别指出过，所以交付前要**分两轮**从全文回扫，不能一次到位。

判据（每次改完念一遍）：**这句话放进一份要交给客户的正式材料里，是"严谨专业"还是"聊天口气"？**
另一条：**删掉这句废话，意思会不会变？** 不会 → 删。

## 第一轮：套话 + 行业缩语

### A. 套话 / 空标签（换成具体动作与结果）

| 禁用 | 换成 |
|---|---|
| 赋能、抓手、闭环、生态化、组合拳、颗粒度 | 具体动作与结果 |
| 沉淀 | 落成 / 记进 |
| 护城河 | 长项 |
| 镜像式互补 | 两者定位不同 |
| 底座（更完备） | 底子 / 基础能力（更全） |
| 开箱即用 | 下载即用 / 直接使用 |
| 落地 / 可落地 | 可以直接照着做 / 写进需求 |
| 全景（作标题可留，作正文修饰词慎用） | 完整 / 全部 |
| "把功夫花在…" | 侧重 / 重点放在 |

| 打补丁（链） | 加一段统一处理 |

## 第二轮：读法标签 + 轻度口语

### C. 读法标签（教读者"怎么读"= AI 典型动作，删）

「一句话说清 / 一句话结论 / 一句话解读 / 一句话总结 / 一句话看清 / 一句话读懂 / 核心要点 / 核心观点 / 核心结论 / 解读 / 小结 / 概览」

- **处理**：直接陈述，删掉标签本身。
- 给提示框加引导语时，用**内容名**：`两者定位：`、`优先级说明：`、`范围说明：`、`标记含义：`——不用读法动词。
- 「执行摘要」是 executive summary 的逐字直译 → 改「核心摘要」。

### D. 轻度口语词（比"变砖 / 卖铲子"轻，但同样要换）

| 禁用 | 换成 |
|---|---|
| 把功夫花在 / 用着顺手 | 侧重…的操作体验 |
| 手感 | 操作体验 |
| 底子 | 基础能力 |
| 很麻烦 / 很烦 | 操作繁琐 / 排查不便 |
| 就能用 | 即可使用 |
| 白白消耗 | 无谓消耗 |
| 活儿 | 任务 |
| 东西 | 物件 |
| 挑片 / 挑 | 选片 / 选择 |
| 抽卡 / 多抽几段 | 重新生成 / 多生成几段 |
| 搞定 / 弄好 / 咋 / 啥 / 说白了 / 咱们 | 中性书面语 |

### E. 硬禁（任何情况都不出现）

emoji 装点（🔥🧱❄🟡✅📌 等）、营销词（干货 / 硬核 / 炸裂 / 保姆级 / 吐血整理 / 敲黑板）。

## 机检

```bash
python scripts/check-language.py <交付HTML或MD>
```

脚本会剥掉 HTML 注释与 `<style>`/`<script>`，逐行扫描上述四类词，命中即打印「类别 · 行号 · 片段」，有命中退出码 1。
**脚本只做初筛**——个别词在特定语境可能确实需要（如源码里出现的英文标识），人工复核每条命中后决定改词还是放行。
